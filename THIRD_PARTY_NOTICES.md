The phone frames used in the README imagery were adapted from this Figma
Community resource:

- **Resource:** [iPhone 17 Mockups](https://www.figma.com/community/file/1560672326379407095/iphone-17-mockups)
- **Creator:** Max Rudberg

The repository contains exported/derived imagery only; it does not redistribute
the original Figma source file.
